# 基于星闪的智能资产追踪系统

## 系统简介

本系统是一个基于星闪（NearLink）技术的智能资产追踪管理系统，提供资产的精确定位、实时监控、借用管理等功能。系统采用现代化的 Web 界面设计，支持多种资产管理业务流程。

## 技术特色

### 星闪技术优势

- **精确定位**：厘米级室内定位精度
- **低延迟**：毫秒级响应时间
- **高可靠**：抗干扰能力强
- **多设备**：支持大量设备并发连接

### 系统架构

- **前端**：HTML5 + CSS3 + JavaScript（原生）
- **后端**：Python Flask 框架
- **数据库**：SQLite（轻量级文件数据库）
- **通信**：RESTful API 接口

## 安装运行

### 环境要求

- Python 3.7+
- Flask 2.0+
- SQLite 3

### 安装步骤

1. 克隆项目代码
2. 安装依赖包：`pip install flask`
3. 运行系统：`python app.py`
4. 访问地址：`http://localhost:5000`

## 数据库设计

系统包含 7 个核心数据表：

- `assets` - 资产基础信息表
- `location_history` - 位置历史记录表
- `borrow_records` - 借用记录表
- `maintenance_records` - 维护记录表
- `inventory_records` - 盘点记录表
- `users` - 用户信息表
- `alerts` - 告警通知表

## API 接口

系统提供完整的 RESTful API 接口：

- `GET/POST /api/assets` - 资产管理接口
- `PUT/DELETE /api/assets/<id>` - 资产操作接口
- `POST /api/borrows` - 借用管理接口
- `POST /api/maintenance` - 维护管理接口
- `POST /api/alerts/<id>/resolve` - 告警处理接口
